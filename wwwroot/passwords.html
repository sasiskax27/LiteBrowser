Настройки менеджера паролей

Перенос паролей из другого браузера
  1. Chrome / Edge / Яндекс / Opera / Brave: Настройки → Пароли (Автозаполнение → Менеджер паролей) → ⋮ → «Экспорт паролей».
  2. Firefox: Пароли (about:logins) → ⋯ → «Экспорт паролей».
  3. Нажмите кнопку ниже и выберите сохранённый CSV-файл. После импорта удалите CSV: в нём пароли не зашифрованы.
Bitwarden, KeePass и другие менеджеры
  1. Из Bitwarden: Инструменты → Экспорт хранилища → формат .csv, затем «Загрузить CSV-файл» выше.
  2. В Bitwarden: нажмите «Экспорт» ниже, затем в Bitwarden: Инструменты → Импорт данных → «Bitwarden (csv)». Этот файл понимают также KeePassXC, 1Password и Proton Pass.
