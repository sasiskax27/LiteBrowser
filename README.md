# LiteBrowser

Лёгкий и безопасный браузер для Windows на C# и WebView2 (движок Chromium, встроенный в Windows 10/11).
Программа — один exe примерно на 7,5 МБ (или 73 МБ со всем необходимым внутри). **Любую функцию можно включить или выключить в настройках.**

## Возможности

**Безопасность**
- Только HTTPS — с предупреждением, если сайт не поддерживает защищённое соединение
- Блокировка рекламы и трекеров, расширенный список (~80 000 доменов рекламы и вредоносных сайтов, StevenBlack) с еженедельным обновлением
- Предупреждение при переходе на опасный сайт
- Строгая защита от слежки, SmartScreen, пароли и формы не сохраняются
- Уведомления от сайтов запрещены, камера/микрофон/геолокация — только с вашего согласия
- Режим инкогнито (Ctrl+Shift+N)

**Новое в 3.3**
- **Разделённый экран** (Ctrl+\): две вкладки рядом, разделитель можно тянуть, двойной клик — поровну
- **Рабочие пространства**: «Учёба», «Работа», «Игры» — у каждого свой набор вкладок, переключение одним кликом (меню → «Рабочие пространства»)
- **Чтение без интернета** (Ctrl+Shift+Y): страница сохраняется целиком в один файл; если сайт не открывается из-за сети — браузер сам покажет сохранённую копию
- **ИИ по всем вкладкам** («какой из открытых товаров дешевле?») и **поиск по истории своими словами** («статья про видеокарты на прошлой неделе»)
- **Группировка вкладок по темам** одной командой: видео, покупки, новости, соцсети, разработка и т. д.

**Новое в 3.2**
- **Lite AI — встроенный ИИ-помощник**, работает прямо на компьютере без интернета (llama.cpp, модели Qwen 2.5 и Gemma 3, ускорение на видеокарте через Vulkan). Кратко пересказать страницу, главные мысли, объяснить, перевести, переписать текст, помочь с кодом. Можно подключить Ollama или любой OpenAI-совместимый сервис (с явным согласием на отправку страниц)
- **Центр безопасности**: оценка защиты, что и чьи трекеры заблокированы, проверка настроек с исправлением в один клик, разрешения сайтов
- **Инструменты разработчика** в боковой панели (Ctrl+Shift+I): сетевые запросы с фильтрами, консоль с выполнением JavaScript, метрики скорости страницы
- **Палитра команд (Ctrl+K)**: поиск по командам, вкладкам, настройкам, закладкам и истории
- Защита загрузок: предупреждение о программах и архивах, метка «из интернета» для SmartScreen, контрольная сумма SHA-256
- Профили (отдельные окна с раздельными данными), заметки и выделения на страницах, перевод страниц, голосовой ввод, чтение вслух, жесты мышью, QR-код страницы, экономия трафика, родительский контроль с PIN-кодом, восстановление вкладок после сбоя

**Новое в 3.1**
- Автообновление с GitHub и предложение стать браузером по умолчанию
- Страница загрузок с историей, скачивание видео/аудио со страницы (прямые файлы)
- Поиск по странице (Ctrl+F), подсказки в адресной строке
- Картинка в картинке, скорость видео, скриншоты (видимая часть и вся страница), режим чтения
- Группы вкладок с цветами, закреплённые вкладки, боковая панель (Ctrl+B)
- Коды 2FA и проверка утечек паролей (Have I Been Pwned, k-анонимность)
- Синхронизация через облачную папку (зашифрованный файл)
- Светлая тема, цвет акцента, обои и свои плитки на стартовой странице

**Блокировщик рекламы**
- Списки фильтров как у uBlock Origin / AdBlock: EasyList, EasyPrivacy, RU AdList, баннеры cookies (~137 000 правил)
- Сетевые правила `||домен^` и правила по адресам (`/ads/*`, `||yandex.ru/ads/`) с `$domain=`, `$third-party`, типами ресурсов и исключениями `@@`
- Индекс правил по токенам, как в uBlock: ~4 мкс на проверку запроса
- Скрытие рекламных блоков `##селектор`, исключения `#@#`, `$document`, `$generichide`
- Реклама на YouTube (работает «как получится» — YouTube борется с блокировщиками)
- Блокировка всплывающих окон без клика пользователя
- Щит в адресной строке: что заблокировано на странице и выключение блокировки для сайта
- Списки обновляются автоматически раз в 4 дня

**Сайты: доверие и разрешения** (клик по замку в адресной строке)
- Обычный / доверенный (без блокировки рекламы и окон) / ненадёжный (без JavaScript, окон, разрешений и паролей)
- Запоминание разрешений (камера, микрофон, геолокация и др.) с возможностью изменить
- Удаление cookies отдельного сайта

**Расширения**
- Установка из Chrome Web Store, Microsoft Edge Add-ons и Firefox Add-ons (кнопка «Установить расширение» на странице магазина)
- Показ прав расширения перед установкой, включение/выключение, удаление
- Окно и настройки расширения открываются во вкладке (WebView2 не показывает значки расширений на панели)
- Расширения для Firefox в основном несовместимы с Chromium — браузер честно об этом скажет

**Менеджер паролей**
- Хранилище с мастер-паролем: AES-256-GCM, ключ через PBKDF2-SHA256 (600 000 итераций), только на этом компьютере
- Предлагает сохранить пароль после входа, заполняет по кнопке-ключу в адресной строке (только по вашему клику)
- Проверка безопасности: слабые и повторяющиеся пароли, оценка надёжности
- Генератор паролей, поиск, копирование с автоочисткой буфера через 30 секунд
- Автоблокировка по времени и при блокировке Windows (Win+L)
- Перенос паролей из Chrome, Edge, Яндекса, Opera, Brave, Firefox и Bitwarden через CSV-экспорт
- Экспорт в CSV в формате Bitwarden (подходит для Bitwarden, KeePassXC, 1Password, Proton Pass)
- Забытый мастер-пароль восстановить нельзя — так задумано

**Обход блокировок**
- Работа через ваш VPN-клиент или Tor: SOCKS5/HTTP-прокси (v2rayN, Hiddify, NekoBox, Clash, Outline, Tor Browser)
- Режим «только выбранные сайты» — заблокированные сайты идут через прокси, остальные напрямую
- Защита от утечки IP через WebRTC
- Браузер сам по себе блокировки не обходит — нужен ваш прокси/VPN/Tor

**Удобство**
- Вкладки с перетаскиванием, значком звука и отключением звука
- Закладки и панель закладок, история с поиском
- Встроенный менеджер загрузок
- Восстановление вкладок после перезапуска, «Открыть закрытую вкладку»
- Заморозка неактивных вкладок для экономии памяти
- Выбор поисковика: DuckDuckGo, Startpage, Brave Search, Google, Яндекс, Bing
- Может быть браузером по умолчанию, ярлыки на рабочем столе и в «Пуске»
- Масштаб страниц (кнопка «100%» на панели, Ctrl + колёсико) и размер самого интерфейса (75–125%)

**Перенос из других браузеров**
- Закладки и история из Chrome, Edge, Яндекс Браузера, Opera, Brave, Vivaldi и Firefox (данные только читаются)
- Экспорт и импорт закладок в HTML-файл — формат, который понимают все браузеры
- Пароли и cookies не переносятся: браузеры их шифруют, а LiteBrowser пароли не хранит

## Установка

Нужны Windows 10/11 и [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0) (для сборки — .NET 8 SDK).

```powershell
powershell -ExecutionPolicy Bypass -File tools\install.ps1
```

Скрипт соберёт exe, положит его в `%LOCALAPPDATA%\Programs\LiteBrowser` и создаст ярлыки. Права администратора не нужны.

Запуск без установки: `dotnet run -c Release`
