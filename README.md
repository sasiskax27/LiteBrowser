# LiteBrowser

Лёгкий и безопасный браузер для Windows на C# и WebView2 (движок Chromium, встроенный в Windows 10/11).
Программа — один exe на 1,5 МБ. **Любую функцию можно включить или выключить в настройках.**

## Возможности

**Безопасность**
- Только HTTPS — с предупреждением, если сайт не поддерживает защищённое соединение
- Блокировка рекламы и трекеров, расширенный список (~80 000 доменов рекламы и вредоносных сайтов, StevenBlack) с еженедельным обновлением
- Предупреждение при переходе на опасный сайт
- Строгая защита от слежки, SmartScreen, пароли и формы не сохраняются
- Уведомления от сайтов запрещены, камера/микрофон/геолокация — только с вашего согласия
- Режим инкогнито (Ctrl+Shift+N)

**Менеджер паролей**
- Хранилище с мастер-паролем: AES-256-GCM, ключ через PBKDF2-SHA256 (600 000 итераций), только на этом компьютере
- Предлагает сохранить пароль после входа, заполняет по кнопке-ключу в адресной строке (только по вашему клику)
- Проверка безопасности: слабые и повторяющиеся пароли, оценка надёжности
- Генератор паролей, поиск, копирование с автоочисткой буфера через 30 секунд
- Автоблокировка по времени и при блокировке Windows (Win+L)
- Перенос паролей из Chrome, Edge, Яндекса, Opera, Brave и Firefox через CSV-экспорт
- Забытый мастер-пароль восстановить нельзя — так задумано

**Обход блокировок**
- Работа через ваш VPN-клиент или Tor: SOCKS5/HTTP-прокси (v2rayN, Hiddify, NekoBox, Clash, Outline, Tor Browser)
- Режим «только выбранные сайты» — заблокированные сайты идут через прокси, остальные напрямую
- Защита от утечки IP через WebRTC
- Браузер сам по себе блокировки не обходит — нужен ваш прокси/VPN/Tor

**Удобство**
- Вкладки с перетаскиванием, значком звука и отключением звука
- Закладки и панель закладок, история с поиском
- Встроенный менеджер загрузок
- Восстановление вкладок после перезапуска, «Открыть закрытую вкладку»
- Заморозка неактивных вкладок для экономии памяти
- Выбор поисковика: DuckDuckGo, Startpage, Brave Search, Google, Яндекс, Bing
- Может быть браузером по умолчанию, ярлыки на рабочем столе и в «Пуске»
- Масштаб страниц (кнопка «100%» на панели, Ctrl + колёсико) и размер самого интерфейса (75–125%)

**Перенос из других браузеров**
- Закладки и история из Chrome, Edge, Яндекс Браузера, Opera, Brave, Vivaldi и Firefox (данные только читаются)
- Экспорт и импорт закладок в HTML-файл — формат, который понимают все браузеры
- Пароли и cookies не переносятся: браузеры их шифруют, а LiteBrowser пароли не хранит

## Установка

Нужны Windows 10/11 и [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0) (для сборки — .NET 8 SDK).

```powershell
powershell -ExecutionPolicy Bypass -File tools\install.ps1
```

Скрипт соберёт exe, положит его в `%LOCALAPPDATA%\Programs\LiteBrowser` и создаст ярлыки. Права администратора не нужны.

Запуск без установки: `dotnet run -c Release`

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| Ctrl+T / Ctrl+W | Новая / закрыть вкладку |
| Ctrl+Shift+T | Открыть закрытую вкладку |
| Ctrl+N / Ctrl+Shift+N | Новое окно / окно инкогнито |
| Ctrl+Tab, Ctrl+1…9 | Переключение вкладок |
| Ctrl+L | Адресная строка |
| Ctrl+D | Добавить / убрать закладку |
| Ctrl+Shift+B | Панель закладок |
| Ctrl+H | История |
| Ctrl+Shift+P | Пароли |
| Ctrl+J | Загрузки |
| Ctrl+, | Настройки |
| Ctrl + / Ctrl − / Ctrl+0 | Масштаб страницы / сброс |
| F5, Alt+← / Alt+→ | Обновить, назад / вперёд |
