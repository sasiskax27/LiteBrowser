# LiteBrowser

Лёгкий и безопасный браузер для Windows на C# и WebView2 (движок Chromium, встроенный в Windows 11).

## Возможности

- **Лёгкий** — программа весит пару мегабайт, использует движок, который уже есть в Windows; фоновые вкладки экономят память
- **Безопасный** — только HTTPS, блокировка рекламы и трекеров, строгая защита от слежки, SmartScreen, пароли и формы не сохраняются, уведомления от сайтов запрещены, доступ к камере/микрофону/геолокации — только с вашего согласия
- **Выбор поисковика** — DuckDuckGo, Startpage, Brave Search, Google, Яндекс, Bing
- Тёмный интерфейс, своя стартовая страница и страница настроек
- Очистка истории, cookies и кэша в один клик

## Запуск

Нужен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) и Windows 10/11.

```
dotnet run -c Release
```

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| Ctrl+T / Ctrl+W | Новая / закрыть вкладку |
| Ctrl+Tab | Следующая вкладка |
| Ctrl+L | Адресная строка |
| Ctrl+, | Настройки |
| F5 | Обновить |
| Alt+← / Alt+→ | Назад / вперёд |
